# Bank Analysis

Streamlit app untuk project business analytics bank.

## Jalankan lokal

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

Letakkan `data_clustering.csv` di folder `data/`. App ini dirancang langsung memakai dataset itu tanpa upload.

## Connector

URL publik nanti bisa kamu isi di:

- `../portfolio_dashboards/streamlit-links.json`
